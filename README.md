# WhatsApp-style Firebase App

This repo contains a working Flutter starter app inspired by WhatsApp, built with Firebase Authentication and Firestore.

Structure:
- `whatsapp_style_app/` - Flutter app project

Important:
- This is a WhatsApp-style clone starter, not a full native app cloning system.
- To use Firebase for real, replace the placeholder values in `lib/firebase_options.dart` by running `flutterfire configure`.

Quick start:

```bash
cd whatsapp_style_app
flutter pub get
flutterfire configure
flutter run
```
